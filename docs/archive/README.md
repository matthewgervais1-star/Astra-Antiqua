# Archive

These are authored banks from before the rebrand. They stay because the rebrand brief forbids deleting corpus substance. No route renders them. The owner decided on 2026-09-29 to move them here from `web/src`.

`docs/archive/web-content/` holds six files:

- `domainReadings.ts`: hand-written life-domain directives, one per domain per tone.
- `weekReadings.ts`: day lines for the week-ahead strip, one per Moon sign.
- `seasonReadings.ts`: readings for each zodiac season, scaled to a thirty-day stretch.
- `oracleDecrees.ts`: one sample oracle decree per culture.
- `methodologyContent.ts`: interpretive notes and methodology sections per culture.
- `transitReading.ts`: the transit reading line composer (verb line, reflection, deity names).

Nothing compiles these files. `web/tsconfig.json` and the gate scripts cover `web/` only.
