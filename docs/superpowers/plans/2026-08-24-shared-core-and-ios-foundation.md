# Shared Core and iOS Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the canonical chart-reading content to shared JSON, port the chart math to a C# core library proven equivalent by golden tests, and scaffold the MAUI iOS head with a macOS CI build.

**Architecture:** Web stays the source of truth; two Node scripts export its data tables to `shared/content/` and its computed outputs to golden fixtures. A `netstandard2.0`+`net8.0` class library (`dotnet/AstraAntiqua.Core`) embeds the JSON and re-implements the five load-bearing web functions (`computeGeocentricLongitude`, `computeAngularPoints`, `longitudeToSign`, `computeWholeSignHouses`, `computeAspects`). xUnit tests assert parity. A `net10.0-ios` MAUI head references Core and builds only in GitHub Actions on macOS.

**Tech Stack:** Node 24 (type stripping + a module-resolution hook for the `@/` alias), .NET SDK 8.0.423 local / .NET 10 in CI, `CosineKitty.AstronomyEngine` (NuGet), `System.Text.Json`, xUnit, GitHub Actions `macos-latest`.

**Spec:** `docs/superpowers/specs/2026-08-24-shared-core-and-ios-foundation-design.md`

## Global Constraints

- Web runtime behavior untouched: only `web/scripts/` and `web/package.json` scripts change; `npm run gates` must stay green.
- `shared/content/*.json` is generated — regenerated via `npm run export:content`, never hand-edited. Generator fails loudly on count mismatches (5 cultures, 10 planets, 50 deities, 120 paragraphs, 12 houses, 12 signs, 5 aspect rules).
- Ephemeris is **geocentric**: Sun via `SunPosition`, Moon via `EclipticGeoMoon`, planets via `GeoVector(aberration: corrected)` → equatorial-to-ecliptic conversion. The library's heliocentric `EclipticLongitude()` helper is never called.
- Orb table is exactly conjunction 8 / sextile 5 / square 7 / trine 7 / opposition 8; aspect detection breaks on first matching rule; pair iteration follows canonical planet order (sun…pluto).
- `LongitudeToSign` throws on non-finite input (mirrors web).
- Golden parity tolerance: longitudes within **0.001°**; signs, houses, aspect kinds/pairs exact.
- Local commands must pass on this machine: `dotnet test` under SDK 8.0.423 (no MAUI workload). The MAUI head is excluded from the solution build filter used locally.
- Commit in reviewable slices with conventional messages.

- [ ] **Step 1: resolver hook.** Node's type stripping doesn't rewrite the `@/*` tsconfig alias, so register a resolve hook:

```js
// web/scripts/resolve-at-alias.mjs — maps the tsconfig "@/*" alias for Node runs.
import { fileURLToPath, pathToFileURL } from "node:url";
import path from "node:path";
import fs from "node:fs";

const SRC = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "../src");

export function resolve(specifier, context, nextResolve) {
  if (specifier.startsWith("@/")) {
    let p = path.join(SRC, specifier.slice(2));
    if (!fs.existsSync(p)) for (const ext of [".ts", ".tsx"]) {
      if (fs.existsSync(p + ext)) { p += ext; break; }
    }
    return nextResolve(pathToFileURL(p).href, context);
  }
  return nextResolve(specifier, context);
}
```
