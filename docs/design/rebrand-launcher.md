# Rebrand launcher prompt

Paste this into a fresh Claude Code session in `L:\Claude Projects\astra-antiqua`:

```text
Read docs/design/rebrand-brief.md and execute it.

You are rebranding the Astra Antiqua web surface (web/). The brief is the
contract: its Inviolable core section is non-negotiable, its Open to change
section really is open, and its verification bar defines done.

Start with Phase 1: build the three named design directions as real rendered
pages, show them to me in the browser at desktop and mobile widths with
screenshots, and STOP for my pick. Do not begin Phase 2 until I choose.

After my pick, execute Phase 2 in one shot per the brief, and present the
finished site with the full verification evidence.
```

Notes:
- Works best in the desktop app or any client with the browser pane, since
  both phases verify visually.
- The Phase 1 stop is a real checkpoint: the pick can happen in the same
  session or a later one; the brief keeps either path consistent.
